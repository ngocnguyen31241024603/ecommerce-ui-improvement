## Cách mở bài

1. Mở [trang chủ trên GitHub Pages](https://ngocnguyen31241024603.github.io/ecommerce-ui-improvement/JavaScript-Labs/).
2. Chọn Lab 08, Lab 09 hoặc Lab 10, sau đó chọn Exercise trong trang danh sách.
3. Khi kiểm tra trên máy, mở thư mục repo bằng VS Code và dùng Live Server để chạy `JavaScript-Labs/index.html`. Mở Chrome DevTools khi Exercise yêu cầu Console, Sources hoặc Network.

Exercise 8.2–8.5, 9.5–9.6 và 10.1–10.2 lần lượt dùng chung trang HTML trong từng nhóm. Các trang danh sách mô tả thao tác tương ứng với mỗi Exercise.
