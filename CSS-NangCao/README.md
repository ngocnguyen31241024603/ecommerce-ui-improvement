Thực hành định vị và dàn trang bằng CSS, xây dựng bố cục responsive, tạo hiệu ứng tương tác và sử dụng lưới Bootstrap 3 trong một trang có nhiều vùng nội dung.

## Nội dung thực hành

| Bài | Nội dung |
| --- | --- |
| 7.1–7.4 | Document flow, relative/absolute positioning và z-index |
| 7.5–7.9 | Float, clear và định vị các lớp phủ |
